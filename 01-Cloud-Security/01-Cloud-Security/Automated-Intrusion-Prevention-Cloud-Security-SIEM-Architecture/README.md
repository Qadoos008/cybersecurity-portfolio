# Automated Intrusion Prevention & Cloud Security SIEM Architecture

## Overview

Designed and implemented a cloud-native security monitoring and automated response architecture using AWS CloudTrail, CloudWatch, SNS, Lambda, IAM, and Wazuh SIEM integration.

## Technologies

- AWS CloudTrail
- AWS CloudWatch
- AWS SNS
- AWS Lambda
- AWS IAM
- AWS S3
- Wazuh SIEM
- Python (boto3)

## Skills Demonstrated

- Cloud Security Engineering
- Compliance Mapping
- Security Automation
- SIEM Integration
- Incident Response
- Cloud Monitoring
