# Threat Simulation & Real-Time Correlation Search Automation

## Overview

Simulated adversarial activity and developed real-time correlation searches to detect, analyze, and alert on malicious behavior within a Splunk-based SOC environment.

The project demonstrates practical detection engineering through attack simulation, correlation search development, alert automation, and security monitoring.
