# Advanced Behavioral Detection Engineering & SOC Dashboarding

## Overview

Developed behavioral detection use cases and centralized SOC dashboards using Splunk SPL and XML parsing techniques to identify reconnaissance and persistence activities.

The project demonstrates practical detection engineering, threat hunting, dashboard development, and behavioral analytics within a Splunk-based security operations environment.
