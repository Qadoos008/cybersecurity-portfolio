# Endpoint Detection & Automated Incident Response Playbook

## Overview

Deployed and configured a Wazuh XDR platform capable of endpoint monitoring, threat detection, and automated incident response through Active Response mechanisms.

The project demonstrates practical implementation of XDR, security automation, endpoint monitoring, threat detection, and automated containment within a simulated enterprise environment.
