# Distributed SIEM Infrastructure Engineering & Attack Simulation Lab

## Overview

Designed and deployed a distributed Splunk SIEM architecture capable of centralized log collection, security monitoring, and attack telemetry analysis across multiple systems.

The environment consisted of an Ubuntu Server hosting Splunk Enterprise, a Windows 11 endpoint generating security telemetry, and a Kali Linux attack platform used to simulate adversarial activity. The project validated end-to-end log collection, centralized monitoring, attack visibility, and SIEM functionality through controlled attack simulations and security event analysis.
